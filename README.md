# The Illusion of Life — 12 Basic Principles of Animation

A modern, responsive, standalone visual gallery illustrating the **12 Basic Principles of Animation** with iconic cube animations.

Inspired by [The 12 Principles](https://the12principles.tumblr.com/) with all external platform bloat, tracking scripts, and platform dependencies removed.

---

## 🎨 The 12 Principles

1. **Squash and Stretch**: Gives the illusion of weight and volume to a moving character/object.
2. **Anticipation**: Prepares the audience for an action.
3. **Staging**: Directs attention and makes an idea unmistakably clear.
4. **Straight Ahead Action and Pose to Pose**: Two key approaches to the drawing process.
5. **Follow Through and Overlapping Action**: Simulates inertia and different rates of motion.
6. **Slow In and Slow Out**: Natural easing, acceleration, and deceleration.
7. **Arcs**: Natural, curved trajectories of motion.
8. **Secondary Action**: Additional action that enriches and supports the main action.
9. **Timing**: The number of frames determining physical speed, mass, and emotion.
10. **Exaggeration**: Pushing expressions and movement for impact while maintaining believability.
11. **Solid Drawing**: Rendering forms with volume, anatomy, balance, and 3D depth.
12. **Appeal**: Magnetic design and personality that captivates the viewer.

## 🚀 Getting Started

### View Locally
Simply open `index.html` in any modern web browser or run a local web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve
```

Then navigate to `http://localhost:8000`.

### Deploy to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
